# AF4 Website

Static Persian RTL brand website for AF4.

## Files
- `index.html`: responsive landing page, styles and interactions.
- `favicon.svg`: brand icon.
- `robots.txt`: crawler guidance.
- `sitemap.xml`: initial sitemap (update canonical URLs if the public hostname changes).

## Publish on Render
Static site, branch `main`, build command `echo "Static AF4 site"`, publish directory `af4-site`.

## Editing
Edit `af4-site/index.html` and commit changes to `main`. With auto-deploy enabled, Render will publish the new version. Do not publish secrets or API keys in this folder.

## SEO note
A sitemap and metadata help crawlers discover the site but do not guarantee indexing or rankings. Verify ownership in Google Search Console and submit the sitemap after the public URL is confirmed.
