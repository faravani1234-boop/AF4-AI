# AF4 AI

دستیار هوش مصنوعی شخصی با رابط فارسی و راست‌چین.

## هدف پروژه
ساخت یک دستیار شخصی با پنل قابل شخصی‌سازی، تاریخچه گفتگو، تنظیمات و امکان اتصال امن به مدل هوش مصنوعی.

## نقشه راه
1. ساخت رابط کاربری واکنش‌گرا و فارسی
2. پیاده‌سازی تاریخچه گفتگو و تنظیمات ظاهری
3. ساخت بک‌اند برای اتصال امن به مدل هوش مصنوعی
4. افزودن آپلود فایل و ابزارهای اختصاصی
5. آماده‌سازی برای استقرار آنلاین

## وضعیت فعلی
نسخه اولیه رابط کاربری در حال ساخت است. تا زمانی که بک‌اند و کلید API به‌صورت امن تنظیم نشوند، پاسخ‌های واقعی هوش مصنوعی فعال نیستند.

## نکته امنیتی
کلیدهای API را داخل فایل‌های فرانت‌اند یا مخزن GitHub قرار ندهید. کلید باید فقط در متغیرهای محیطی بک‌اند نگهداری شود.
