# AF4 AI

دستیار هوش مصنوعی شخصی فارسی با رابط راست‌چین و برند AF4؛ ساخته‌شده برای عباس فراوانی.

## وضعیت فعلی
- رابط کاربری فارسی و واکنش‌گرا
- اتصال رابط چت به بک‌اند امن
- نگهداری تاریخچه در همان مرورگر
- حافظهٔ محلی قابل بازبینی و پاک‌کردن؛ یادداشت‌ها فقط روی دستگاه می‌مانند
- بستهٔ استیکرهای تصویری AF4 که در حالت آفلاین هم در دسترس است
- در نسخهٔ Android، مدل زبانی Qwen3-1.7B با LiteRT-LM برای پاسخ محلی پس از آماده‌سازی اولیه
- تنظیمات ظاهری ذخیره‌شونده در همان مرورگر
- جست‌وجوی وب از طریق Responses API، در صورت فعال بودن
- محدودیت تعداد درخواست و بررسی ساختار پیام‌ها

## اجرای محلی
به Node.js نسخه 20 یا جدیدتر نیاز داری.

1. پروژه را روی کامپیوتر دانلود کن.
2. داخل پوشه پروژه ترمینال باز کن و بزن: `npm install`
3. فایل `.env.example` را کپی کن و نام کپی را `.env` بگذار.
4. کلید API را فقط داخل `.env` روی دستگاه خودت یا در تنظیمات محرمانه هاست قرار بده.
5. دستور `npm start` را اجرا کن.
6. در مرورگر باز کن: `http://localhost:3000`

## تنظیمات و انتخاب هوشمند مدل
- مسیریاب بر اساس نوع درخواست، سرویس مناسب را در اولویت می‌گذارد: کارهای کدنویسی ابتدا Anthropic و OpenAI؛ درخواست‌های تحلیلی ابتدا OpenAI و Anthropic؛ درخواست‌های کوتاه ابتدا Groq و Gemini.
- اگر کلید یک ارائه‌دهنده تنظیم نشده باشد، آن سرویس رد می‌شود. در صورت قطعی، محدودیت نرخ، خطای اعتبار/کلید یا خطای پاسخ، سرویس بعدی امتحان می‌شود و سرویس مشکل‌دار برای مدتی موقتاً کنار گذاشته می‌شود.
- `AI_PROVIDER_PRIORITY`: اختیاری؛ فهرست ارائه‌دهنده‌های ترجیحی با کاما، مانند `gemini,groq,openai,anthropic,openrouter`. مسیریاب همچنان اولویت نوع درخواست را در نظر می‌گیرد و بقیه را برای پشتیبانی نگه می‌دارد.
- `GEMINI_API_KEY` و اختیاری `GEMINI_MODEL`: Google Gemini؛ مدل پیش‌فرض `gemini-2.5-flash`
- برای چرخش خودکار بین چند کلید از متغیرهای اختیاری `GEMINI_API_KEYS`، `GROQ_API_KEYS`، `OPENAI_API_KEYS`، `ANTHROPIC_API_KEYS` و `OPENROUTER_API_KEYS` استفاده کن؛ کلیدها را با کاما جدا کن. متغیر تک‌کلیدی قدیمی همچنان پشتیبانی می‌شود. کلیدهای چندگانه و تک‌کلیدی را هم‌زمان در یک فهرست تکراری وارد نکن.
- `GROQ_API_KEY` و اختیاری `GROQ_MODEL`: Groq؛ مدل پیش‌فرض `llama-3.3-70b-versatile`
- `OPENAI_API_KEY` و اختیاری `OPENAI_MODEL`: OpenAI API؛ مدل پیش‌فرض `gpt-4.1-mini`
- `ANTHROPIC_API_KEY` و اختیاری `ANTHROPIC_MODEL`: Anthropic API؛ مدل پیش‌فرض `claude-sonnet-4-5`
- `OPENROUTER_API_KEY` و اختیاری `OPENROUTER_MODEL`: OpenRouter؛ مدل پیش‌فرض `openrouter/free`
- `PORT`: پورت وب‌سرور.
- این‌ها APIهای مستقل‌اند؛ اشتراک ChatGPT یا Claude Code به‌تنهایی کلید API نمی‌دهد. Claude Code خودش یک عامل/ابزار برنامه‌نویسی است و مستقیماً مثل API چت به‌عنوان یک endpoint استفاده نمی‌شود؛ برای مسیریابی چت از Anthropic API استفاده می‌شود.
- انتخاب فعلی بر اساس قواعد نوع درخواست است، نه آزمون زنده و قطعی کیفیت همه مدل‌ها. هزینه، سهمیه و دسترسی هر ارائه‌دهنده تابع حساب همان سرویس است.

## راه‌اندازی رایگان سرور
1. در Google AI Studio یک کلید API بساز: https://aistudio.google.com/apikey
2. در Render گزینه New Blueprint را انتخاب و مخزن GitHub را وصل کن؛ فایل `render.yaml` تنظیمات سرویس رایگان را آماده کرده است.
3. کلید را فقط در متغیر محرمانه `GEMINI_API_KEY` در Render وارد کن؛ کلید را داخل اپ یا GitHub قرار نده.
4. برای فعال‌کردن پشتیبان‌ها، کلیدهای اختیاری `GROQ_API_KEY`، `OPENAI_API_KEY`، `ANTHROPIC_API_KEY` و `OPENROUTER_API_KEY` را در Environment سرویس Render اضافه کن. حداقل یک کلید معتبر لازم است؛ هر کلیدی که تنظیم نشده باشد خودکار نادیده گرفته می‌شود.
5. پس از انتشار، آدرس `https://...onrender.com` را در تنظیمات اپ، قسمت «آدرس سرور هوش مصنوعی» وارد کن.
6. سرویس رایگان ممکن است بعد از بی‌کاری متوقف شود و درخواست اول پس از بیدار شدن دیرتر پاسخ دهد. سهمیه رایگان مدل نیز محدود و قابل تغییر است.

## نکات مهم
- اشتراک ChatGPT و اعتبار API جدا هستند.
- هرگز کلید API را در GitHub، فرانت‌اند یا پیام چت قرار نده.
- تاریخچه فعلی فقط در همان مرورگر ذخیره می‌شود؛ هنوز حساب کاربری یا حافظه همگام‌شده بین دستگاه‌ها وجود ندارد.
- استفاده از مدل و جست‌وجوی وب ممکن است هزینه API داشته باشد.
- این نسخه هنوز تمام امکانات ChatGPT را ندارد. قابلیت‌های صوتی، تولید تصویر، تحلیل فایل، حافظه پیشرفته، ورود کاربران و ابزارهای اختصاصی باید جداگانه اضافه و آزمایش شوند.

## نقشه راه
1. آزمایش اتصال مدل و جست‌وجوی وب
2. نمایش مرتب‌تر منابع وب
3. حافظه قابل‌ویرایش برای پروژه‌ها و ترجیحات
4. آپلود و تحلیل فایل و تصویر
5. صدا و گفتار
6. ورود کاربران، کنترل مصرف و استقرار امن


## ایجنت اینستاگرام (آزمایشی و با تأیید انسانی)

- پنل مدیریت: `/instagram-agent.html`
- بررسی وضعیت: `GET /api/instagram/status` (نیازمند `Authorization: Bearer <INSTAGRAM_AGENT_ADMIN_TOKEN>`)
- فهرست موارد منتظر تأیید: `GET /api/instagram/pending`
- دریافت webhook: `GET/POST /api/instagram/webhook`
- تأیید و ارسال پاسخ دایرکت: `POST /api/instagram/approve/:id` با JSON شامل `{"reply":"متن پاسخ" }`
- رد کردن مورد: `POST /api/instagram/dismiss/:id`

**پیش‌نیازهای واقعی:** اکانت Instagram باید Creator یا Business باشد، Meta App و مجوزهای لازم ساخته و تأیید شوند و اسرار/توکن‌های معتبر در Environment سرویس Render قرار گیرند. مسیر webhook فقط بعد از تنظیم `INSTAGRAM_WEBHOOK_VERIFY_TOKEN` و `META_APP_SECRET` معتبر است. هیچ پاسخی به‌طور خودکار ارسال نمی‌شود؛ ارسال از صف فقط پس از تأیید دستی انجام می‌شود.

**محدودیت فعلی:** صف در حافظه است و با restart/redeploy پاک می‌شود؛ این نسخه برای تست اولیه است، نه تولید پایدار. رویدادهای دریافتی در صف قرار می‌گیرند؛ تولید پیش‌نویس هوش مصنوعی، پاسخ به کامنت، انتشار پست/ریل، آمار و ذخیره‌سازی پایدار هنوز در این مرحله فعال نشده‌اند. قبل از استفاده واقعی باید ذخیره‌سازی پایدار، OAuth/token lifecycle، و endpointهای جداگانه برای کامنت و انتشار پیاده‌سازی و آزمایش شوند.

## مدل آفلاین اندروید
نسخهٔ Android مدل Qwen3-1.7B را در بستهٔ نصب همراه دارد (حدود 977 مگابایت فایل مدل). آماده‌سازی اولیه، فایل را به فضای خصوصی برنامه کپی و SHA-256 آن را بررسی می‌کند؛ برای نصب و آماده‌سازی حدود 2 گیگابایت فضای آزاد در نظر بگیر. پس از آماده‌سازی، پاسخ‌های متنی می‌توانند بدون اینترنت تولید شوند. پاسخ‌های زنده و جست‌وجوی وب همچنان به اتصال اینترنت نیاز دارند و کیفیت مدل محلی با مدل‌های ابری یکسان نیست.

## حافظه و استیکرها
- یادداشت‌های حافظه فقط در حافظهٔ محلی همان دستگاه نگهداری می‌شوند و از بخش تنظیمات قابل ویرایش یا پاک‌کردن‌اند.
- در چت می‌توانی با عبارت «یادت باشه: ...» یک یادداشت محلی ثبت کنی. موارد شبیه رمز، کلید API و اطلاعات حساس خودکار ذخیره نمی‌شوند.
- استیکرهای تصویری AF4 به‌صورت فایل‌های SVG محلی بسته‌بندی شده‌اند و سرویس‌ورکر آن‌ها را برای استفادهٔ آفلاین کش می‌کند.
