# AF4 AI

دستیار هوش مصنوعی شخصی فارسی با رابط راست‌چین و برند AF4؛ ساخته‌شده برای عباس فراوانی.

## وضعیت فعلی
- رابط کاربری فارسی و واکنش‌گرا
- اتصال رابط چت به بک‌اند امن
- نگهداری تاریخچه در همان مرورگر
- تنظیمات ظاهری ذخیره‌شونده در همان مرورگر
- جست‌وجوی وب از طریق Responses API، در صورت فعال بودن
- محدودیت تعداد درخواست و بررسی ساختار پیام‌ها

## اجرای محلی
به Node.js نسخه 20 یا جدیدتر نیاز داری.

1. پروژه را روی کامپیوتر دانلود کن.
2. داخل پوشه پروژه ترمینال باز کن و بزن: `npm install`
3. فایل `.env.example` را کپی کن و نام کپی را `.env` بگذار.
4. کلید API را فقط داخل `.env` روی دستگاه خودت یا در تنظیمات محرمانه هاست قرار بده.
5. دستور `npm start` را اجرا کن.
6. در مرورگر باز کن: `http://localhost:3000`

## تنظیمات
- `OPENAI_API_KEY`: کلید API برای پاسخ‌های واقعی
- `OPENAI_MODEL`: مدل مجاز حساب API؛ پیش‌فرض `gpt-4.1-mini`
- `AF4_ENABLE_WEB_SEARCH`: جست‌وجوی وب فعال است مگر مقدار آن `false` باشد
- `PORT`: پورت وب‌سرور

## نکات مهم
- اشتراک ChatGPT و اعتبار API جدا هستند.
- هرگز کلید API را در GitHub، فرانت‌اند یا پیام چت قرار نده.
- تاریخچه فعلی فقط در همان مرورگر ذخیره می‌شود؛ هنوز حساب کاربری یا حافظه همگام‌شده بین دستگاه‌ها وجود ندارد.
- استفاده از مدل و جست‌وجوی وب ممکن است هزینه API داشته باشد.
- این نسخه هنوز تمام امکانات ChatGPT را ندارد. قابلیت‌های صوتی، تولید تصویر، تحلیل فایل، حافظه پیشرفته، ورود کاربران و ابزارهای اختصاصی باید جداگانه اضافه و آزمایش شوند.

## نقشه راه

4. آپلود و تحلیل فایل و تصویر
5. صدا و گفتار
6. ورود کاربران، کنترل مصرف و استقرار امن
